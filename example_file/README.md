# 工業物聯網範例檔案

這個目錄提供可直接拿來測試上傳、儲存與索引流程的公開範例，檔案名稱已重新命名，原始來源與 SHA-256 如下。使用前請依各來源頁面的授權條款確認再散布權限。

| 檔案 | 類型 | 用途 | 來源 |
| --- | --- | --- | --- |
| `iiot_factory_robot.jpg` | JPG | 工廠自動化／機器人視覺範例 | [Wikimedia Commons: Factory Automation Robotics Palettizing Bread](https://commons.wikimedia.org/wiki/File:Factory_Automation_Robotics_Palettizing_Bread.jpg) |
| `iiot_giga_press.png` | PNG | 巨型壓鑄機與工業機器人影像範例 | [Wikimedia Commons: Giga Press at Tesla Fremont](https://commons.wikimedia.org/wiki/File:20200922-giga-press-idra-ol6100cs-tesla-fremont-dcm1-robot-megacasting-crop.png) |
| `iiot_factory_process.mp4` | MP4 | 工業製程短影片（目前保留作樣本，暫不可上傳） | [Internet Archive: Technicolor for Industrial Films](https://archive.org/details/Technico1949) |
| `iiot_factory_process.avi` | AVI | 同一工業影片的 AVI 容器範例（目前保留作樣本，暫不可上傳） | [Internet Archive: Technicolor for Industrial Films](https://archive.org/details/Technico1949) |

| `iiot_sensor_alert.eml` | EML | 含 multipart MIME 的設備告警／支援郵件範例 | [SampleFile: EML samples](https://samplefile.com/samples/document/eml/) |
| `iiot_industry_report.pdf` | PDF | 工業物聯網產業報告與案例內容 | [IoT4Industry: IoT in Industry](https://iot4industry.salzburgresearch.at/wp-content/uploads/FINAL_IoT_Industry_D.1_December-2015.pdf) |
| `iiot_sensor_inventory.xlsx` | XLSX | 多工作表感測器盤點表格式範例 | [SampleFile: XLSX samples](https://samplefile.com/samples/document/xlsx/) |

Office 三份檔案是公開的格式／解析測試 fixture，檔名依本專案用途重新命名；內容不代表特定工廠或客戶資料。
